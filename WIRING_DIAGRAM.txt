MOTOR ESCs (Signal Wires Only - Power from PDB/Battery)
================================================================================

        FRONT
         / \
    FL      FR     Motor Layout (X configuration)
   (D3)    (D5)    
    CCW     CW     Rotation Directions:
      \   /        FL & RR: Counter-Clockwise (CCW) ↺
       \ /         FR & RL: Clockwise (CW) ↻
       / \
      /   \
    RL      RR
   (D9)    (D6)
    CW      CCW
         |
        REAR

    ESC Wiring:
    ┌─────────────┬──────────────┬───────────────────┐
    │ ESC         │ Arduino Pin  │ Rotation          │
    ├─────────────┼──────────────┼───────────────────┤
    │ Front Left  │ D3           │ CCW (↺)           │
    │ Front Right │ D5           │ CW  (↻)           │
    │ Rear Right  │ D6           │ CCW (↺)           │
    │ Rear Left   │ D9           │ CW  (↻)           │
    └─────────────┴──────────────┴───────────────────┘

    Each ESC:
    ┌────────────┐
    │    ESC     │
    │            │
    │ [R][B][Y]  │  <- Motor wires (swap any 2 to reverse)
    │  │  │  │   │
    │ [R][B][O]  │  <- Power: Red=Battery+, Black=GND, Orange=Signal
    └──┼──┼──┼───┘
       │  │  └──────> To Arduino Pin (D3/D5/D6/D9)
       │  └─────────> Common GND
       └────────────> Battery + (via PDB)

BATTERY VOLTAGE DIVIDER (A0)
================================================================================

    Battery +
       │
       │
      [R1]  1.5kΩ Resistor
       │
       ├────> A0 (Analog Read)
       │
      [R2]  1kΩ Resistor
       │
       └────> GND

    Voltage Calculation:
    - Max input: 12.5V (3S LiPo fully charged = 12.6V)
    - Arduino reads 0-5V on A0
    - Formula: Vbat = (Vadc × (R1 + R2)) / R2
    - For 12.6V battery: A0 reads ~5.04V (within tolerance)

================================================================================

    LEFT STICK                       RIGHT STICK
    (Throttle & Yaw)                 (Pitch & Roll)

    ┌──────────────┐                 ┌──────────────┐
    │   ╔═══╗      │                 │   ╔═══╗      │
    │   ║ L ║      │                 │   ║ R ║      │
    │   ╚═══╝      │                 │   ╚═══╝      │
    │              │                 │              │
    │ VCC GND VRx  │                 │ VCC GND VRx  │
    │  │   │   │   │                 │  │   │   │   │
    │     VRy  SW  │                 │     VRy  SW  │

       │   │   │                        │   │   │

       │   │                            │   │
       │   └─────> A0 (Throttle)        │   └─────> A2 (Pitch)
       │                                │
       └─> 5V                           └─> 5V
       └─> GND                          └─> GND

    Joystick Pinout (typical 5-pin):
    1. VCC  -> 5V
    2. GND  -> GND
    3. VRx  -> Horizontal axis analog output
    4. VRy  -> Vertical axis analog output
    5. SW   -> Push button switch (optional, not used)

⚠️  CRITICAL REMINDERS
================================================================================

1. NRF24L01 MUST HAVE:
   ✅ 10µF capacitor between VCC and GND (on module itself)
   ✅ 3.3V power (NOT 5V!)
   ✅ Short wires (< 10cm for SPI connections)

2. MOTOR DIRECTIONS:
   ✅ FL & RR: Counter-Clockwise (CCW) ↺
   ✅ FR & RL: Clockwise (CW) ↻
   ✅ Swap any 2 motor wires to reverse direction

3. SAFETY:
   ✅ Test all motors WITHOUT propellers first
   ✅ Use smooth motor start feature (A7 button)
   ✅ Verify LED shows disarmed when arm switch HIGH

4. CALIBRATION:
   ✅ Must be done on perfectly level surface
   ✅ Calibrate before EVERY flight session
   ✅ Hold calibration button (A6) for 2 full seconds

5. COMMON GROUND:
   ✅ Arduino GND, battery GND, all ESC GNDs must be connected
   ✅ No ground = no communication!
