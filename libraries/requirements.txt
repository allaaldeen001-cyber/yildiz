# Arduino Library Requirements for Quadcopter Drone Project
# ============================================================
#
# Installation Instructions:
# 1. Open Arduino IDE
# 2. Go to Sketch → Include Library → Manage Libraries
# 3. Search for each library name below
# 4. Click "Install" for each one
#
# Note: Some libraries are built-in to Arduino IDE

# ============================================================
# CORE LIBRARIES (Built-in)
# ============================================================

Wire
# Description: I2C communication library
# Used for: MPU6050 and MS5611 sensor communication
# Version: Built-in with Arduino IDE
# No installation needed

Servo
# Description: PWM control library
# Used for: ESC (motor) control
# Version: Built-in with Arduino IDE
# No installation needed

SPI
# Description: SPI communication library
# Used for: nRF24L01+ radio module
# Version: Built-in with Arduino IDE
# No installation needed

# ============================================================
# EXTERNAL LIBRARIES (Must Install)
# ============================================================

RF24 by TMRh20
# Description: nRF24L01+ radio communication library
# Used for: Wireless remote control communication
# Version: 1.4.7 or later
# Install from: Library Manager
# GitHub: https://github.com/nRF24/RF24
# License: GPL v2

I2Cdev by jrowberg
# Description: I2C device library (helper for MPU6050)
# Used for: Simplified I2C communication
# Version: Latest
# Install from: Library Manager or GitHub
# GitHub: https://github.com/jrowberg/i2cdevlib
# License: MIT
# Note: Search for "I2Cdev" in Library Manager

MPU6050 by jrowberg
# Description: MPU6050 IMU library
# Used for: Reading gyroscope and accelerometer data
# Version: Latest
# Install from: Library Manager or GitHub
# GitHub: https://github.com/jrowberg/i2cdevlib/tree/master/Arduino/MPU6050
# License: MIT
# Note: Requires I2Cdev library (install I2Cdev first)

MS5611 by Rob Tillaart
# Description: MS5611 barometric pressure sensor library
# Used for: Altitude measurement
# Version: 0.4.2 or later
# Install from: Library Manager
# GitHub: https://github.com/RobTillaart/MS5611
# License: MIT

# ALTERNATIVE LIBRARIES (Optional)

# ============================================================
# INSTALLATION METHODS
# ============================================================

# Method 1: Arduino Library Manager (Recommended)
# ------------------------------------------------
# 1. Arduino IDE → Sketch → Include Library → Manage Libraries
# 2. Search for library name
# 3. Click Install
# 4. Wait for installation to complete

# Method 2: Manual Installation from GitHub
# ------------------------------------------
# 1. Download library ZIP from GitHub
# 2. Arduino IDE → Sketch → Include Library → Add .ZIP Library
# 3. Select downloaded ZIP file
# 4. Restart Arduino IDE

# Method 3: Manual Installation to Libraries Folder
# --------------------------------------------------
# 1. Download library from GitHub
# 2. Extract to Arduino libraries folder:
#    Windows: C:\Users\[username]\Documents\Arduino\libraries\
#    Mac: ~/Documents/Arduino/libraries/
#    Linux: ~/Arduino/libraries/
# 3. Restart Arduino IDE

# ============================================================
# VERIFICATION
# ============================================================

# After installing all libraries, verify by:
# 1. Arduino IDE → Sketch → Include Library
# 2. You should see all libraries listed under "Contributed libraries"
# 3. Try compiling the FlightController.ino sketch
# 4. If compilation succeeds, all libraries are correctly installed

# ============================================================
# TROUBLESHOOTING
# ============================================================

# Problem: "Library not found" error
# Solution: 
# - Check library is installed in correct folder
# - Restart Arduino IDE
# - Reinstall library

# Problem: "Multiple libraries found" warning
# Solution:
# - Remove duplicate library folders from libraries directory
# - Keep only the latest version

# Problem: Compilation errors with library code
# Solution:
# - Update to latest library version
# - Check library compatibility with Arduino IDE version
# - Try alternative library (see optional libraries above)

# Problem: "Not enough memory" error
# Solution:
# - Some libraries use more memory than others
# - Try alternative lightweight libraries
# - Optimize code (remove debug Serial.print statements)
# - Use F() macro for strings: Serial.println(F("Text"));

# ============================================================
# LIBRARY DEPENDENCY TREE
# ============================================================

# Flight Controller Dependencies:
# └─ Wire (built-in)
# └─ Servo (built-in)
# └─ SPI (built-in)
# └─ RF24
# └─ I2Cdev
#    └─ Wire
# └─ MPU6050
#    └─ I2Cdev
#    └─ Wire
# └─ MS5611
#    └─ Wire

# Remote Controller Dependencies:
# └─ SPI (built-in)
# └─ RF24

# ============================================================
# MEMORY USAGE ESTIMATES
# ============================================================

# Flight Controller:
# - Sketch: ~18 KB / 32 KB Flash (56%)
# - Global variables: ~800 bytes / 2048 bytes RAM (40%)
# - Safe margins for modifications

# Remote Controller:
# - Sketch: ~8 KB / 32 KB Flash (25%)
# - Global variables: ~400 bytes / 2048 bytes RAM (20%)
# - Plenty of room for features

# ============================================================
# VERSION COMPATIBILITY
# ============================================================

# Arduino IDE Version: 1.8.x or 2.x
# Arduino Core: 1.8.5 or later
# Board: Arduino AVR Boards (Nano, Uno, Mega compatible)

# Tested Configurations:
# ✓ Arduino IDE 1.8.19 + Arduino AVR Boards 1.8.5
# ✓ Arduino IDE 2.2.1 + Arduino AVR Boards 1.8.6

# ============================================================
# ADDITIONAL NOTES
# ============================================================

# 1. RF24 Library Configuration:
#    The RF24 library works out of the box for Arduino Nano
#    No special configuration needed

# 2. MPU6050 Library Notes:
#    Uses DMP (Digital Motion Processor) features if needed
#    Current project uses raw data for simplicity
#    Can be upgraded to use DMP for better performance

# 3. MS5611 Library Notes:
#    Set resolution in code: MS5611_ULTRA_HIGH_RES
#    Higher resolution = slower updates but more accurate

# 4. Memory Optimization:
#    If running low on memory:
#    - Remove Serial.print() debug statements
#    - Use F() macro for constant strings
#    - Reduce buffer sizes
#    - Consider using PROGMEM for constant data
